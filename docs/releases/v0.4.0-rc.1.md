# KaliMac v0.4.0-rc.1

首个公开预发布候选：在 Mac 终端使用项目专属 Kali CLI 环境。
本轮冻结新功能，交付已有功能、首次上手手册和可核验的安装包。

## 使用者得到什么

- **执行与共享**：`init` 创建项目环境，`run` 执行工具，`shell` 进入交互 bash；
  项目根目录映射为 `/workspace`，输出与退出码返回 Mac 终端。
- **看清当前状态**：`status [--json]`、`doctor`、`tools`，分别用于状态总览、深入诊断和精选工具探测。
- **显式恢复任务**：`sessions` 查看会话，`cancel <id>` 取消指定任务；异常退出后不再手抄底层 docker exec。
- **管理环境代际**：`env switch` 切换本地同平台镜像，`rollback` 单代回退，`recover` 收尾中断事务。
- **查看与清理资源**：`env list` 区分 CURRENT/PREVIOUS/RETAINED 等角色；
  `env remove <完整容器ID>` 只删除身份核验通过、已停止的保留容器。
- **安装可追溯**：包内二进制包含源码 SHA、工作区状态和架构；安装/卸载按清单操作。

与内部 `0.4.0-p3` 相比，本轮不新增运行时功能，只更新版本身份、手册与发布验收脚本。

## 下载与首次上手

Release 附件：

- `km-0.4.0-rc.1-darwin-arm64.tar.gz` — Apple Silicon。
- `km-0.4.0-rc.1-darwin-amd64.tar.gz` — Intel Mac 交叉编译包，实机验收待补。
- `SHA256SUMS` — 两个压缩包的 SHA256。
- `RELEASE-VERIFICATION.txt` — 本次发布提交、验证命令、实际结果与平台边界。

先核对校验和，再按 [首次上手手册](../user-guide.md) 或包内 QUICKSTART.md 操作。
安装包用户无需 Go，但需要本机 Docker Desktop。包内提供镜像 Dockerfile，
不包含 Kali 镜像；首次构建需联网。精选六项为 Python、curl、jq、file、OpenSSL、nmap。

## 发布门禁

发布对象必须是通过 CI 的 master 提交，且版本常量、tag、安装包版本一致。
包从干净检出构建；发布验收直接消费待上传的压缩包，不重新构建另一份二进制替代。

验证命令：

```bash
make fmt-check
go vet ./...
go vet -tags=integration ./...
go test -count=1 ./...
go test -race -count=1 ./...
go build ./...
go test -tags=integration -count=1 -timeout 15m -v ./tests/integration/
DIST=/绝对路径/本次产物 bash scripts/package.sh
python3 tests/acceptance/release_walkthrough.py \
  --archive /绝对路径/本次产物/km-0.4.0-rc.1-darwin-arm64.tar.gz \
  --checksums /绝对路径/本次产物/SHA256SUMS \
  --expected-commit <发布提交完整SHA> --evidence /绝对路径/验收证据
```

本机安装版覆盖：中文空格路径、双向共享、工具与状态查询、PTY shell、stop/start、
强杀后的 sessions/cancel 恢复、环境切换/回退/list/remove、卸载金丝雀与零容器残留。
准确的退出状态、SHA256、CI URL 与测试计数以 Release 的验证附件为准。

## 行为边界与升级

- 首发仍是候选版；主要实测平台为 macOS/arm64。Linux/amd64 CI 回归通过与
  Intel macOS 实机验收是两件事，Intel 实机项保持待补。
- 项目文件双向共享。环境切换与回退不撤销项目文件改动，文件版本请交给 Git/备份管理。
- 回退槽位只有一代；`env remove` 永久删除目标容器可写层，不重建容器，不删除项目文件和镜像。
- 强杀宿主客户端后，容器任务可能继续运行。先 sessions 核对，再 cancel；不自动结束仍存活的任务。
- 同一项目一次执行一个 km 工具任务或交互 shell；自建脱离会话的进程不由该会话清理。
- `tools` 仅探测精选清单的 PATH 可用性，不保证版本或功能完整，不自动安装软件。
- stop 保留环境；卸载只删除安装清单，保留项目、状态、容器和镜像。
- 已使用 env 功能的项目可能具有 state_version 2 或未完成事务。旧客户端会按门禁拒绝；
  不把“换回旧二进制”当作状态降级方案。先用本版处理未完成事务，再按需要 env rollback。
- 包未提供 Developer ID 签名/公证的发布保证；校验和用于核对附件完整性，不等同于签名认证。
